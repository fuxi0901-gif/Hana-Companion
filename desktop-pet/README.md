# Hana 桌宠（Desktop Pet）

参考 [Clawd on Desk](https://github.com/rullerzhou-afk/clawd-on-desk) 的形态，把已有的
Live2D 角色缩小到桌面上实时交流的桌宠窗口。基于 Electron 的透明置顶无边框窗口，
渲染页为 `frontend/pet.html`（新增文件，不影响网页版）。

**后端零改动**：桌宠直接复用现有 `/client-ws` WebSocket 协议与静态资源挂载，
控制接口由新增的 `pet_launcher.py` 以独立路由挂载（仅监听 127.0.0.1）。

## 运行项目即自动显示桌宠

只要装过一次依赖，以后**不需要**再手动启动桌宠：

```
cd desktop-pet
npm install        # 仅首次需要（已内置 npmmirror 镜像加速 Electron 下载）
```

之后正常启动项目即可，服务端就绪后桌宠会自动出现在桌面：

```
uv run run_server.py            # 或双击 start-companion.bat / start-fast.bat
```

- 不想让桌宠自动弹出：`uv run run_server.py --no-pet`；
  或在网页版「设置 → 桌宠」里关掉「启动时自动显示桌宠」（等价于
  `desktop-pet/settings.json` 中 `autoShow: false`）。
- 未安装 `desktop-pet/node_modules` 时只打印提示，不影响后端启动。
- 关闭服务端（Ctrl-C / 关窗口）会顺带优雅退出桌宠进程。

## 手动启动（可选）

```
cd desktop-pet
npm start
# 或指定后端地址：
npm start -- --server=http://127.0.0.1:12393
```

后端未启动时桌宠会自动每 4 秒重试，启动后自动加载。

## 操作方式

| 操作 | 效果 |
|---|---|
| 拖动角色 | 移动桌宠窗口（位置自动记忆） |
| 单击角色 | 触发命中区动作 + 显示名字牌 |
| 双击角色 | 弹出文字输入框，Enter 发送 |
| 按住空格 / 按住 🎤 | 说话，松开发送（16kHz，与网页版同一 ASR 链路） |
| 说话时抢话 | 自动发送 interrupt-signal 打断播报 |
| 右键 | 菜单：**设置…**、置顶、大小、形象（Live2D 模型）、跟随网页当前角色、角色、启动时自动显示、打开网页版、重启、退出 |
| 托盘（樱花点） | 显示/隐藏、退出点击穿透、**设置…**、打开网页版、退出 |

## 桌宠设置窗口（右键 →「设置…」）

`frontend/pet-settings.html` 是一个独立的小窗口，和网页版「设置 → 桌宠」面板共用
同一套本机接口（`GET /api/pet`、`/api/characters`、`/api/pet/skins`、
`/api/pet/web-character`、`POST /api/pet/settings`），因此它写的就是
`desktop-pet/settings.json`，已经运行的桌宠窗口在 1.2 秒内应用，不需要重启：

- 显示桌宠窗口 / 启动项目时自动显示 / 始终置顶 / 鼠标穿透（开启时窗口里会提示改用
  托盘菜单恢复）
- 大小滑块（0.4~2.5，实时百分比）
- 跟随网页当前角色 + 当前跟随到的是谁；关闭后角色、形象下拉可用，改动立刻生效
- 打开网页版 / 关闭（窗口右上角关闭即可，再次右键选「设置…」会重新聚焦同一个窗口）

入口有三个：桌宠右键菜单「设置…」、托盘菜单「设置…」（点击穿透时用这个），以及
命令行 `npm start --prefix desktop-pet -- --open-settings`（在桌宠窗口被其他置顶窗口
挡住时最方便）。窗口只有界面，不含任何后端逻辑。

## 在项目里选择桌宠（网页版「设置 → 桌宠」）

打开 `http://127.0.0.1:12393` → 设置抽屉中的「桌宠」区块，可勾选显示/隐藏、
启动时自动显示、始终置顶，选择角色与形象（Live2D 模型），拖动缩放，或退出进程。
面板通过本机接口读写同一份设置，改动会即时同步到已经运行的桌宠窗口：

| 接口 | 作用 |
|---|---|
| `GET /api/pet` | 是否已安装 / 运行中 + 当前设置 |
| `POST /api/pet/show` \| `/hide` | 显示（必要时拉起进程）/ 隐藏（进程保活） |
| `POST /api/pet/quit` | 退出桌宠进程 |
| `POST /api/pet/settings` | 合并写入设置（仅白名单键，非法值 400） |
| `GET /api/pet/skins` | 桌宠可显示的全部 Live2D 模型 |
| `GET /api/pet/web-character` | 网页端当前使用的角色 + 桌宠自己的角色（只读） |

路由由 `pet_launcher.init_pet_route()` 提供，只接受本机请求，且不改 `src/`。

## 与网页人物实时同步

默认开启「跟随网页当前角色」：在网页版（或手机／其他设备的页面）切换角色，
桌宠会在 1~3 秒内换成同一个人物——因为角色文件（`conf.yaml` 或
`characters/*.yaml`）本身就带着性格提示词、显示名、Live2D 形象与语音，桌宠对
自己的会话补发同一个 `switch-config`，所以**形象、说话性格、长期记忆都同步**
（记忆按 `conf_uid` 存在 `chat_history/<conf_uid>/core_memory.md` 与
`fts_index.db`，同一角色的所有会话共享检索）。

- 实现方式：网页端的角色选择只存在于该连接的 `ServiceContext` 里，并不落盘；
  桌宠每 2 秒向 `GET /api/pet/web-character?exclude=<自己的 client_uid>` 只读地
  比对"网页当前角色"与"桌宠当前角色"，不一致才切换，并去重已在途的请求。
  比对的是「角色文件 + 显示名 + 形象」签名，所以只改人设或只换形象也会跟着变。
- 开了跟随就以网页角色为准：之前在桌宠上手动固定的 Live2D 形象会自动让位
  （面板里「桌宠形象」同时置灰）。在桌宠右键「形象」里另选一个则视为刻意定制，
  会自动关闭跟随。
- 同时开着多个网页标签时，以**最近换过角色的那个页面**为准（新连接、刷新后回到
  默认角色的后台标签不会把桌宠带偏）；都不曾切换过时取最新连接的页面。
- 关掉开关（面板勾选框或桌宠右键「跟随网页当前角色」）后，桌宠固定在你手动选的
  角色上；在桌宠右键「角色」里手动选一个，会自动关闭跟随。
- 刚关掉开关时面板会把当前跟随的角色写入手动值，不会出现"显示的和屏幕上不是
  同一个人"的情况。
- 注意：网页刷新后回到默认角色（上游不持久化所选角色），桌宠会跟着回到默认；
  会话内的最近逐条对话记录仍按连接隔离（上游设计，两个浏览器标签之间也
  如此）；跨会话共享的是该角色的长期记忆与全文检索。

## 共享设置 `desktop-pet/settings.json`

服务端启动器、网页面板与 Electron 进程都以该文件为唯一状态源（原子写入、
按 mtime 轮询，1.2 秒内生效），首次运行自动生成：

| 键 | 含义 |
|---|---|
| `autoShow` | 运行项目时是否自动拉起桌宠 |
| `visible` | 窗口是否可见（false 时进程仍保活） |
| `followWeb` | 是否跟随网页端当前角色（默认 true） |
| `character` | 桌宠自己的角色文件（`switch-config`，`conf.yaml` = 跟随默认）；跟随开启时由桌宠写回实际值 |
| `petUid` | 桌宠本次会话的 `client_uid`，由渲染页上报，用于把桌宠自己从"网页角色"里排除 |
| `model` | 强制使用的 Live2D 形象名，`""` = 跟随角色配置；跟随开启时由被跟随的角色决定 |
| `scale` | 大小 0.4 ~ 2.5 |
| `alwaysOnTop` / `clickThrough` | 置顶 / 点击穿透 |
| `quitRequested` | 跨进程退出信号（由启动器写入，桌宠轮询后自杀） |

窗口位置记在 Electron 的用户数据目录（`desktop-pet.json`），与仓库设置分离；
`settings.json` 与 `pet.lock`（存活心跳）都是运行时文件，已加入 `.gitignore`。

## 功能说明

- **状态驱动动画**：思考中/说话中/出错在气泡状态栏提示；LLM 情绪标签经
  `audio.actions.expressions` 映射为 Live2D 表情；播放音量数组驱动口型。
- **缩放**：右键菜单 5 档大小（45%~150%），窗口以"脚底"为锚点缩放，角色始终
  站在桌面下沿。
- **点击穿透**：右键菜单勾选后鼠标事件穿过桌宠；从托盘菜单恢复交互。
- **语音/文字对话**：与网页版共用同一后端会话、角色与记忆系统。

## 已知限制

- Electron 透明窗口在 Windows 上不支持系统级圆角阴影，已用窗内投影代替。
- 点击穿透模式无法通过窗口内右键恢复（鼠标事件已被穿透），请用托盘菜单恢复。
